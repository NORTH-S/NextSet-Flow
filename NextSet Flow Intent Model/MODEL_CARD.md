# NextSet Intent Classifier v1 — 模型说明

**状态：已训练、已独立合成测试的实验候选版本。日期：2026-10-27。**

## 模型是什么

本项目实际使用监督学习拟合的七分类模型。输入中英文健身需求，输出 `legs / upper / full / push / pull / clarify / unsupported`。没有调用外部模型 API，也没有使用预训练模型权重。

最终验证选择了字符 2–5 gram TF-IDF（12,000 个特征）与 L2 多类逻辑回归（C=4）。权重和偏置有 84,007 个数值参数。JSON 文件 1,424,885 字节，约 1.36 MiB；推理可以只用 Python 标准库或 JavaScript。

## 数据与训练

350 条助手编写的合成种子语句，每类 50 条；仅对训练数据增加时间/排队上下文，得到 1,050 条训练行。98 条另行编写的合成验证语句用于选择六个固定候选设置和追问阈值。独立贡献者在训练前冻结 105 条最终合成测试语句，训练及参数选择未读取它们。

没有真实用户、真实健身房记录、专家审核或生产反馈。各集合没有规范化全文重复或 family 标识重叠；这不能证明语义模板、词汇或作者偏差完全独立。

## 实测结果

| 项目 | 结果 |
| --- | --- |
| 验证集原始准确率 | 74/98，75.5% |
| 最终合成测试原始准确率 | 76/105，72.4% |
| 最终测试 macro F1 | 0.722 |
| 被直接接受为五种训练类别的请求 | 42/105，覆盖率 40.0% |
| 上述直接分类中正确的数量 | 36/42，85.7% |
| 被误接受为训练类别的超出范围请求 | 1 条 |

必须同时报告直接分类的准确程度和覆盖率。低分请求会转为 `clarify`，因此“已接受样本的正确率”不是整个模型的准确率。模型的 softmax 分数没有校准，不等于预测正确的真实概率。阈值是在验证集上选择的，最终测试没有达到验证阶段的接受正确率目标。

完整分语言结果、混淆矩阵、失败示例和逐条输出见 `reports/Evaluation.md`、`reports/metrics.json` 与 `reports/test_predictions.jsonl`。没有根据此轮最终测试重新训练或修改阈值。

## 适用范围与限制

- 适合课程实验、展示小型文本分类学习过程、探索网页本地推理和收集下一轮标注需求。
- 目前泛化能力有限，尤其是否定修正、混合语言、模糊需求和超出范围的识别。不能作为成熟产品的可靠用户理解层。
- 此版本只输出类别。没有训练时间、器械、经验、偏好的字段提取，也不生成训练计划。
- `unsupported` 不是可靠的医疗/安全过滤器；不能据此给出医学适应性或训练动作处方。
- 没有预测器械占用时间、连接传感器或共享真实健身房状态。
- 首次下载/打开和手机浏览器的性能没有实测；Python 推理耗时不能代替浏览器性能。

## 推理、复现与版本冻结

`runtime/classifier.py` 与 `runtime/classifier.js` 使用相同的 Unicode 规范化、TF-IDF、权重和追问策略。六项运行时检查通过，覆盖 20 条另行编写的 Unicode/边界探针；两端逐类别分数误差小于 1e-7。训练导出时也与 scikit-learn 的原生输出进行数值一致性检查。

另有两项独立离线 HTML 行为检查通过，覆盖无网络/无模块加载运行、真实提交与输出渲染、不可信输入按文本处理。共八项软件检查；它们不等于分类准确率，也不代替浏览器视觉验证。训练复现得到相同的特征、权重、偏置和追问策略，详见 `reports/reproducibility.json`。

`model/selection.json` 保存模型哈希、训练/验证哈希、全部候选设置和最终阈值。固定种子与依赖版本用于复现权重；元数据含时间戳和耗时，整个 JSON 不承诺逐字节相同。评估脚本拒绝重复使用同一最终测试更新成绩；后续若根据本轮错误改进模型，需另建新的未使用测试集。

此文件夹保留独立的冻结模型及评估证据。同一模型现已集成到相邻 `NextSet Flow Demo`；集成没有改变模型权重或阈值。网站的规则字段提取、确认流程和调度逻辑见最新 v4 验证说明。
